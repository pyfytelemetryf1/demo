## About this repo

This is a guided tour / demo of **PyFy Telemetry - F1 Performance Analysis**, a telemetry analysis tool for F1 sim racing.

Browse analysis charts, coaching insights, session comparisons, and example telemetry data - all from your browser. 

**[Launch the demo →](https://pyfytelemetryf1.github.io/demo/)**

## About the tool

Capture F1 telemetry and turn it into corner-by-corner coaching you can act on right away: find the top 3 turns where you lose time against a reference lap, and how to fix your technique, consistency, racing lines, and ERS management to find lap time. Supports both the 2026 and 2025 regulations and telemetry formats, including Madrid. Currently compatible with EA Sports F1 25*, including the 2026 Season Pack* (F1 26* DLC).
